# Восстановление проекта Vanguard Arena

В архиве — законченный проект «Vanguard Arena»: 1v1 top-down PvP-дуэли (canvas-игра с джойстиком, способностями Q/W/E/R, ИИ-соперником, локальным матчмейкингом и интеграцией с Telegram Mini App). Стек архива полностью совпадает с текущим проектом (TanStack Start + React 19 + Tailwind v4 + shadcn), так что его можно перенести как есть.

## Что будет сделано

1. Распаковать архив и перенести весь `src/` из него в проект (заменив плейсхолдер главной страницы на экран игры), а также `public/`, `components.json` и конфиги, где они отличаются.
2. Не копировать git-метаданные; `.lovable/project.json` текущего проекта оставить нетронутым.
3. Синхронизировать зависимости из `package.json` архива (доустановить недостающие пакеты) и убедиться, что сборка и типы проходят.
4. Проверить игру в превью: меню → поиск матча → арена → результаты, отсутствие ошибок в консоли.

## Технические детали

- Переносимые модули: `src/game/*` (config, core, combat/GameEngine, ai, input, rendering, mobs), `src/components/game/*`, `src/services/matchService.ts`, `src/services/telegram.ts`, `src/routes/index.tsx`, `src/routes/__root.tsx`, `src/styles.css`, `src/components/ui/*`.
- `src/routeTree.gen.ts` не редактируется вручную — регенерируется дев-сервером.
- Флаги в `GAME_CONFIG.features` (нейтральные мобы, Core, sudden death, апгрейды за Essence, Shockwave) сейчас выключены — оставляем как есть до отдельной задачи.

## Дальше

После переноса скажите, над чем работаем: включение Sprint 3 (мобы/Core/sudden death), онлайн-матчмейкинг через Lovable Cloud вместо локального ИИ, баланс/фидбек боя или UI меню и профиля.
